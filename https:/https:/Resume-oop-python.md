• Class & Object: Menggunakan class PenontonKonser untuk mencetak dua object berbeda, yaitu orang1 dan orang2.
• Class Attributes: Atribut nama, kota, dan band didefinisikan di dalam class dengan nilai awal string kosong (""), lalu diisi nilainya melalui masing-masing object.
• Methods & Parameter self: Memiliki keempat method sesuai materi (perkenalan, menyapa, asal_kota, dan membahas_band) yang menggunakan self untuk mengakses data milik object itu sendiri.
